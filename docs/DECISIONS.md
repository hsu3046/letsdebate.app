# 제품 및 구현 결정

## 2026-09-06 — 1대1 디베이트 토너먼트로 전환

사용자는 전체 UI 개선을 요청했고, 작업 중 다대다 토론보다 1대1 토너먼트가 더 재미있겠다는 방향을 제시했다. OpenRouter 키는 나중에 제공하며, OpenRouter 중심의 다양한 모델 선택을 원했다.

- 기본 경험은 4강, 확장 선택지는 8강의 단판 토너먼트다.
- 모바일을 우선하되 데스크톱에 전체 대진표와 넓은 탐색 화면을 제공한다.
- 초기 스타일은 종이색·짙은 그린·파스텔이었다. 후속 디자인 결정에서 스포츠·캐릭터 중심 컵 테마로 발전시켰다. 기존 브랜드 로고는 유지한다.
- 모델 검색, 제공사 필터, 무료 모델 필터, 이름/출력 가격 정렬을 지원한다. 추정 인기 순위는 만들지 않는다.
- 키가 없어도 주제 탐색·북마크·모델 선택·대진표 생성까지 가능하다.
- 토론자와 심판 모두 OpenRouter로 실행한다. 별도 Google 키를 요구하지 않는다.
- 선택된 모델을 다른 모델로 자동 대체하지 않는다. 실패한 경기에는 우승자나 진출자를 만들지 않는다.
- 모델 이름은 심판에게 보내지 않는다. 심판은 사용자가 지정하며 참가 모델과 같으면 이를 안내한다.
- 각 경기는 사용자가 직접 시작한다. UI에는 발언·심판 호출 횟수와 토큰 가격을 표시한다.
- 기록을 자동 삭제하지 않는다. 삭제는 명시 확인을 받고, 별도 Markdown 내보내기를 제공한다.
- 기존 캐릭터 토론과 기록을 유지해 기존 사용자의 데이터 접근을 보장한다.

## 2026-09-06 — 귀여운 선수들이 출전하는 왈가왈부컵

사용자는 전체적으로 월드컵·스포츠 느낌을 더하고, 기존 에셋을 최대한 활용해 귀여운 캐릭터성이 먼저 느껴지도록 요청했다.

- 기존 5개 모델 캐릭터와 MC, 브랜드 로고를 재사용한다. 중앙 팀 매핑으로 모델 선택·대진표·기록의 프로필을 일치시킨다.
- 메인은 선수 카드의 등번호·VS·잔디 코트·트로피와 3단계 경기 입장권으로 구성한다. 캐릭터 팀 소개를 추가한다.
- 제목은 둥근 Jua, 본문은 Pretendard. 진한 그린·노랑·산호·블루를 사용해 승부감과 귀여움을 함께 표현한다.
- 원본 그림은 덮어쓰거나 편집하지 않는다. 다른 제공사는 기존 브랜드 캐릭터 로고를 사용하며, OpenRouter 모델 선택에는 제한을 추가하지 않는다.
- 메인의 팀 대결은 예시다. 임의 능력치·순위·관중 수·라이브 경기는 만들지 않는다.

## 검증에서 보강한 부분

- 320px 페이지 여백(16px)과 대진표의 바깥 확장 여백을 일치시켜 5px 넘침을 제거했다.
- 저장된 기존 설정은 hydration 이후 편집 상태로 초기화해 첫 렌더링과 복원 시점의 불일치를 줄인다.
- 모달은 native dialog를 사용하고 닫을 때 원래 버튼으로 포커스를 돌린다.
- 경기 runId로 늦은 응답·중단된 실행·중복 판정이 다음 대진표를 변경하지 못하게 한다.


## 2026-09-06 — 운영자가 AI를 제공하는 방식으로 전환

사용자는 OpenRouter 등의 개인 키 입력 기능을 없애고 모든 AI 연결을 서비스가 제공하도록 요청했다. 위의 개인 키·가격 표시 관련 결정은 이 항목으로 대체한다.

- 키 입력 화면·저장소·설정 탐색을 제거하고 `/settings`는 이용 가이드로 연결한다.
- 클라이언트 요청에는 키를 포함하지 않는다. 토너먼트는 키 필드가 포함된 요청을 거부한다.
- 토너먼트와 기존 캐릭터 토론 모두 서버 OpenRouter 연결을 공유한다. 서버 미설정은 503이며 이용자에게 설정을 요구하거나 모의 경기를 생성하지 않는다.
- 모델 선택은 이름·제공사 검색으로 제공한다. 외부 토큰 가격·무료 필터·크레딧 안내는 제거한다. 운영자의 선택적 제공 모델 목록은 서버에서도 검증한다.
- 기존 캐릭터는 실제 OpenRouter 카탈로그에서 확인한 제공사별 모델 ID를 사용한다. 모델 ID는 `src/lib/ai/config.ts`에 모은다.
- 이전 브라우저 키만 삭제하고 저장한 대진표·토론 기록·북마크는 보존한다.

## 2026-09-06 — PR 리뷰 이후 로그인과 운영 한도

사용자 요청에 따라 기존 UI·토너먼트·캐릭터 20종을 PR #1로 분리하고 Codex 리뷰 완료 후 `codex/service-auth-and-limits`에서 후속 구현한다. PR #1의 979eb6d는 주요 지적 없이 리뷰를 완료했으며 merge와 운영 배포는 별도다.

- Google 로그인과 계정 이용 내역을 Supabase Auth/Postgres로 구현한다. 전용 프로젝트를 권장하며 기존 AIB 프로젝트 통합 여부는 미확정이다. 외부 프로젝트를 임의 변경하지 않는다.
- 공개 탐색과 대진 생성은 로그인 없이 제공하고 AI 실행은 검증된 계정만 허용한다.
- 서버 원장과 원자적 RPC로 계정별 일일 한도와 중복 실행을 제어한다. 초기에는 Redis를 추가하지 않는다.
- 실패 시에도 시작한 요청 횟수를 보존한다. DB 장애에서 유료 호출을 허용하던 이전 fallback을 제거한다.
- 운영 활성화 플래그, OpenRouter 키, 비어 있지 않은 모델 허용 목록이 모두 있어야 실행한다. 전역 비용 상한은 OpenRouter 대시보드에서 함께 설정한다.
- 대진표는 브라우저에 유지하며 서버에는 사용량과 완료 응답 재사용에 필요한 원장을 저장한다. 실제 OAuth/AI 실호출, 기기 간 기록 동기화, 비용 자동 대사와 보존·탈퇴 정책은 후속 운영 설정 범위다.
