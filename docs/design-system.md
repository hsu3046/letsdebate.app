# 왈가왈부 디자인 시스템

2026-09-06 · WalGaWalBu Cup

## 시각 방향

사용자의 후속 요청에 따라 월드컵·스포츠 분위기와 기존의 귀여운 캐릭터성을 중심으로 구성한다. 크림색 바탕에 잔디 코트, 등번호가 있는 선수 카드, 노란 입장권, 굵은 테두리와 짧은 그림자를 사용한다. 메인과 주제 카드부터 모델 선택·대진표·발언·우승까지 동일한 팀 마스코트가 이어진다.

| 용도 | 값 |
| --- | --- |
| 기본 배경 | `#fffaf0` |
| 주요 텍스트·선수 카드 테두리 | `#203b32` |
| 주요 버튼 | `#24734b` |
| 경기장 줄무늬 | `#246345` / `#2a6a48` |
| 트로피·선택 포인트 | `#f8d94f` |
| 일반 경계선 | `#d4dbc9` |
| 팀 컬러 | coral / blue / yellow / pink / mint |

`src/styles/experience.css`는 공통 레이아웃·상태·반응형 구조를, 그 뒤의 `src/styles/championship.css`는 컵 테마와 선수 카드·코트·팀 소개를 정의한다. 기존 `globals.css`의 Tailwind 색상 토큰과 연결한다. 제목과 브랜드는 둥근 Jua, 본문은 Pretendard와 Noto Sans KR fallback을 사용한다. 기존 토론 인용용 RIDIBatang은 유지한다. Jua를 참조하는 `--cup-display`는 next/font 변수가 존재하는 body에 정의한다.

## 기존 에셋 사용

`src/lib/mascots.ts`가 제공사와 팀 캐릭터의 공통 매핑이다. 캐릭터는 제공사를 나타내는 시각적 마스코트이며, 실제 모델의 성격·역량·순위를 규정하지 않는다. 모델 ID와 이름은 OpenRouter 선택값을 그대로 사용한다.

| 팀 | 캐릭터 | 기존 public 에셋 |
| --- | --- | --- |
| Anthropic / Claude | 소피 | `/avatars/avatar_sophie.jpeg` |
| OpenAI / GPT | 빅터 | `/avatars/avatar_victor.jpeg` |
| Google / Gemini | 헨리 | `/avatars/avatar_henry.jpeg` |
| xAI / Grok | 레오 | `/avatars/avatar_leo.jpeg` |
| DeepSeek | 맥스 | `/avatars/avatar_max.jpeg` |
| 진행자 | MC | `/avatars/avatar_mc.jpeg` |
| 브랜드·기타 제공사 | 공통 클럽 로고 | `/logo_light.svg` |

선수 소개는 원본 정사각형 그림을 보여주고, 작은 프로필은 CSS 원형 프레임으로 얼굴을 강조한다. 원본 이미지 파일은 수정하지 않는다. 메인의 대결은 예시로 표시하며, 실제 대진과 승점은 사용자가 만든 토너먼트에서만 표시한다.

추천 주제는 원본 일러스트를 얼굴 중심으로 확대해 큰 원형 마스코트 두 개와 작은 VS 배지로 표현한다. 선수 카드 프레임은 히어로와 팀 소개에 사용한다. 주제 하단은 “이 주제로 토론하기”로 다음 행동을 명확히 표시한다. 최근 토너먼트 빈 상태의 시작 버튼은 높이 52px의 메인 그린 버튼이다. 상단 모바일 브랜드의 CUP 배지는 제거하며, 메인 제목은 “AI 모델들의 / 토론 배틀!”로 서비스의 목적을 바로 알린다.

서비스 제공 안내의 “POWERED BY OPENROUTER”에는 [OpenRouter 공식 저장소의 로고](https://github.com/OpenRouterTeam/sign-in-with-openrouter/blob/main/public/openrouter-logo.svg)를 원본 그대로 사용한다. 로컬 파일은 `public/logos/openrouter.svg`, 원본 MIT 고지는 `public/logos/openrouter.LICENSE.txt`다. 푸터 회사명은 “© 2026 에이아이비 주식회사”이며 `https://aib.vote/`에 연결한다.

## 반응형

- 767px 이하: 상단 브랜드, 하단 네 개 탐색, 세로 중심 화면.
- 768px 이상: 데스크톱 사이드바. 넓은 화면은 콘텐츠와 요약을 2열로 배치한다.
- 4강·8강 대진표는 좁은 화면에서 자체 가로 스크롤을 사용한다. 페이지 전체가 가로로 넘치면 안 된다.
- 모바일 모델 선택에는 제한된 목록 스크롤과 하단 라인업 바로가기를 제공한다.
- 메인은 1024px 이상에서 소개와 코트를 2열로 배치하고, 그 아래에서는 1열로 배치한다. 세로 배치의 경기장은 컨테이너 전체 폭을 채운다. 팀 소개는 좁은 화면에서 수평 스크롤과 scroll-snap을 사용한다.
- 주요 검증 폭: 320, 390, 768, 1024, 1112, 1440px.

## 상호작용과 접근성

주 탐색 탭은 메인 그린 `#24734b`와 크림색 글자를 사용한다. 비대칭 둥근 모서리, 아이콘 칸의 점선, 작은 리본과 짧은 그림자로 경기 티켓 형태를 만든다. 모바일 하단 탭도 같은 색상과 형태를 사용하며, 선택 상태의 hover에서도 글자 대비를 유지한다.

모바일 입력은 16px 이상, 브라우저 확대는 허용한다. 포커스 표시와 본문 건너뛰기 링크, 제목 계층, 버튼 이름, 토글의 aria-pressed, 내비게이션 aria-current를 사용한다. 경계 선택과 제거는 키보드 버튼으로 조작할 수 있다.

모달은 native dialog로 포커스를 가두고 Escape로 닫으며 원래 버튼에 포커스를 돌린다. 제공사 드롭다운은 투명 backdrop의 React onClick으로 외부 탭을 처리한다. 모션은 reduced-motion 설정을 따르며, 지속 실행하는 배경 애니메이션은 기본 화면에서 제외한다.

## 서비스 제공 방식

개인 API 키 입력·크레딧 연결 UI는 제공하지 않는다. 메인은 “다양한 AI를 / 한 경기장에”로 안내하고 대결할 모델 선택으로 연결한다. 모바일 상단에는 설정 대신 이용 가이드를 제공한다. 모델 선택에는 검색과 제공사 필터를 유지하고 외부 토큰 요금·무료 모델 필터는 표시하지 않는다.

## 한글 문구 원칙

- 제목·버튼·짧은 안내는 쉼표와 마침표를 자제하고 간결하게 쓴다. 질문에는 물음표를 쓰며 브랜드의 “왈가왈부컵!”은 유지한다.
- 설명과 상태 안내는 자연스러운 해요체를 기본으로 한다. 긴 설명은 문장을 나누고 마침표를 써서 읽기 쉽게 한다.
- “의견 보내기”, “이 주제로 토론하기”, “다시 토론하기”처럼 버튼의 다음 행동을 명확히 쓴다.
- 핵심 용어는 주제·선수·토너먼트·경기·심판·기록으로 통일한다. 실제 AI 모델의 이름과 제공사 이름은 그대로 표기한다.
- “해 주세요”, “해 보세요”, “진행 중”, “일시 정지”처럼 띄어쓰기를 지킨다. 진행 상태의 말줄임표는 “…”를 쓴다.
- 법률 문서의 내용과 사용자가 작성한 주제·저장된 발언은 문구 정리 대상으로 일괄 변경하지 않는다.

## AI 모델 간 토론 배틀 강조

서비스의 첫 메시지는 “여러 AI 모델이 같은 주제로 1대1 토론 배틀을 펼친다”이다. 메인 제목은 “AI 모델들의 / 토론 배틀!”로 쓰고 GPT·Claude·Gemini·Grok·DeepSeek 계열 이름을 첫 화면에 노출한다. 모델이 주장과 반박을 펼치고 AI 심판의 판정으로 다음 라운드에 진출한다는 흐름을 설명한다.

스포츠 디자인과 기존 귀여운 캐릭터는 유지한다. 팀 소개는 AI 모델 이름을 가장 크게 쓰고 캐릭터 이름을 보조로 표시한다. 실제 모델·버전은 배틀을 만들 때 선택한다. 히어로 경기장에는 구체적인 토론 주제와 “주장 → 반박 → AI 심판 판정”을 표시하며 예시임을 명시한다. 주제·생성·도움말·기록·공유 미리보기 문구도 같은 개념을 사용한다.

## 캐릭터 카드 Series 01

기존 노란 로봇의 둥근 얼굴·헤드셋·안테나·굵은 윤곽선을 유지한 20종 일러스트다. 직업을 드러내는 의상·도구와 세밀한 실내 배경을 제거하고 표정·손짓·헤드셋·색상으로 개성을 구분한다. 단순한 파스텔 배경과 큰 기하 도형을 사용한다.

- 이미지: `public/characters/series-01/01-lumi.png`부터 `20-bibi.png`까지 개별 PNG
- 이름·번호·한 줄 성격: `src/lib/characterCards.ts`와 `public/characters/series-01/manifest.json`
- 생성 프롬프트: `assets/characters/series-01/prompts.json` (내장 image_gen 사용)
- `/characters`에서 20종 카드와 원본 저장 링크를 제공한다. 메인 모델 소개의 “새 캐릭터 20종 보기”로 접근한다.
- 카드 프레임·이름·번호는 UI에서 표시한다. 이미지에는 글자나 특정 AI 제공사 로고를 넣지 않아 다른 모델과의 조합에도 재사용할 수 있다. 캐릭터의 성격은 AI 모델의 능력을 규정하지 않는다.
- 원본 20종은 각각 1254×1254 PNG이며 `assets/characters/series-01.zip`에 메타데이터와 생성 프롬프트를 함께 묶었다.
- 검증: 프로덕션 빌드·TypeScript·변경 파일 ESLint 통과. 20개 이미지 로딩과 원본 다운로드, 320·390·768·1024·1112·1440px 가로 넘침 없음, 브라우저 실행 오류 없음을 확인했다.

- 상단 소개와 푸터 슬로건은 ‘최신 AI들의 진검 토론 승부’로 통일한다. 상단 브랜드 표기는 ‘왈가왈부’다

- 검증: 빌드·수정 파일 lint 통과. 320~1559px 너비 및 데스크톱 높이 600px 이상에서 페이지 가로 넘침과 사이드바 스크롤 없음

- 검증: 빌드·수정 파일 lint 통과. 320 / 390 / 768 / 1112 / 1559px 가로 넘침 없음. 데스크톱 홈과 모바일 진행 단계 시각 확인 완료

- 선수 페이지 제목은 ‘15명의 최신 AI / 토론으로 진검 승부’로 표시한다
- 카드 번호는 제거하고 개발사 이름을 17px, 국가명을 15px로 표시한다. TEAM 표기도 모델 계열 대신 개발사 이름을 사용한다
- 모델명 20px / 공식 로고 28px로 강조하며 좁은 카드에서는 줄바꿈을 허용한다

- 능력치 안내는 대표 선수 수 옆에 표시한다. 국가 필터 15px / 국기 22px, 선수 수 14px·보통 굵기를 사용한다
- 캐릭터 한마디는 캐릭터 이름 아래에 배치한다

- 카드에는 ‘왈가왈부 자체 평가’를 표시하며 산정 방식과 재미 지표 설명은 안내 모달에서 제공한다

- 몸값은 낮을수록 저렴한 방향으로 표시한다. 입력:출력 2:1 평균 단가를 C라 하면 round(100 × C / (C + 2))를 사용하며 0~100점으로 제한한다. 나머지 능력치 방향은 유지한다
